# FIT90 — Full update (2026-09-10)

هذه النسخة تضم الكود الحالي كاملًا من `backend` و`frontend` و`docs`.

## تصحيح خطأ النشر السابق

يُنشئ البناء الحالي لباك إند NestJS ملف التشغيل في `dist/src/main.js`.
كان PM2 في السيرفر يشير إلى المسار القديم `dist/main.js`، لذلك توقف التطبيق بعد آخر نشر وظهر 503.

هذه الحزمة تمنع تكرار الخطأ بطريقتين:

1. سكربت cPanel يتوقف إذا لم يتولد `dist/src/main.js` بعد البناء.
2. أوامر root تعيد تعريف عملية `fit90` في PM2 لتشغّل `dist/src/main.js` وتحفظ الإعداد.

## حماية البيانات

لا يشمل الأرشيف `.env` أو `node_modules` أو مخرجات البناء أو الملفات المرفوعة أو النسخ الاحتياطية.
ولا ينفذ السكربت أي أمر لتعديل قاعدة البيانات، بما في ذلك `prisma migrate deploy` و`prisma db push` والاستيراد والـseed.

نفّذي `TERMINAL-COMMANDS.txt` من حساب cPanel، ثم أعطي `ROOT-PM2-COMMAND.txt` لمسؤول root فقط.
