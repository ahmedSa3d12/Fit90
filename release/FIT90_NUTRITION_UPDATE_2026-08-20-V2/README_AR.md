# تحديث التغذية — FIT90

هذه الحزمة تطبق تحديث التغذية فقط، وتشمل:

- نظام حضور أخصائي التغذية الشهري والحجز الديناميكي حسب مدة الخدمة.
- التحقق من رصيد الاشتراك أو الدفع عند الحضور.
- لوحة الحجز الشهرية للتغذية.
- API التطبيق: يعيد لكل فترة حضور حالة الحجز ووقت الفتح والغلق، حتى يظهر للتطبيق «لم يبدأ الحجز» قبل الموعد المحدد.
- تصحيح التكرار الأسبوعي: فتح وغلق الحجز يتحركان مع كل موعد متكرر. مثال: موعد 27 أغسطس يفتح يوم 26 أغسطس.
- migrations الخاصة بالتغذية فقط.

لا تحتوي الحزمة على قاعدة بيانات تجريبية، ولا تستخدم `backend/deploy.sh` لأن هذا السكربت مخصص للنشر الأول وقد يستورد بيانات اختبارية.

## قبل الرفع

- خذي نسخة احتياطية من قاعدة بيانات الإنتاج من cPanel.
- تأكدي أن تطبيق FIT90 يعمل بالفعل وأن ملف `.env` الموجود على السيرفر صحيح.
- السكربت يفحص سجل Prisma أولًا؛ إذا طلب منك التوقف لا تكملي وأرسلي لي ناتج Terminal.
- لا تشغلي هذا التحديث على تطبيق مختلف أو قاعدة بيانات مختلفة.

## أوامر Terminal على السيرفر

من الصورة، الـApplication root لديكِ هو غالبًا `~/fit90.metacodecx.com` لأنه يحتوي `dist` و`public` و`prisma` و`.env`.

1. من File Manager: افتحي مجلد `fit90.metacodecx.com`، ارفعي ملف ZIP داخله ثم اختاري **Extract**. سيتكون مجلد باسم `FIT90_NUTRITION_UPDATE_2026-08-19`.
2. من cPanel → Terminal شغّلي:

```bash
cd ~/fit90.metacodecx.com
bash FIT90_NUTRITION_UPDATE_2026-08-19/deploy-nutrition-update.sh "$PWD"
```

إذا كان cPanel يضع التطبيق في مسار مختلف، استخدمي المسار الظاهر في **Setup Node.js App → Application root** بدلًا من `~/fit90.metacodecx.com`.

بعد ظهور `Nutrition update completed`:

1. من cPanel → Setup Node.js App اختاري تطبيق FIT90.
2. اضغطي **Restart**.
3. افتحي `https://fit90.metacodecx.com/login` واختبري صفحة التغذية.

## ماذا يفعل السكربت؟

1. ينشئ Backup للكود الحالي في `~/fit90/backups/nutrition-...`.
2. يضيف migrations التغذية ويشغل `npx prisma migrate deploy`.
3. يحدّث Prisma Client.
4. ينسخ Backend الجاهز وواجهة الموقع الجاهزة.
5. ينشئ ملف Passenger restart؛ ثم يظل Restart من cPanel هو الخطوة الموصى بها.

## ملاحظة مهمة عن الجداول الموجودة مسبقًا

إصلاح التكرار الأسبوعي يطبق تلقائيًا على أي جدول تغذية جديد يتم إنشاؤه بعد التحديث. الجداول المنشأة قديمًا تحتفظ ببياناتها كما هي؛ راجعي أي مواعيد مستقبلية متكررة تم إنشاؤها قبل التحديث وعدليها من «الجداول الشهرية» إذا كان تاريخ الفتح والغلق غير صحيح.
