رفع استيراد Fit90 على السيرفر

1. في phpMyAdmin اختاري قاعدة البيانات metacodecx_fit90 فقط.
2. من Export خذي نسخة احتياطية كاملة بصيغة SQL قبل التنفيذ.
3. اختاري Import ثم ارفعي الملف fit90_production_import_metacodecx.sql من هذه الحزمة.
4. اضغطي Go وانتظري حتى تظهر نتيجة في آخر الصفحة.

النتيجة الناجحة المطلوبة:
- precheck_passed = 1
- members_imported = 2688
- subscriptions_imported = 4706
- receipts_imported = 4677
- potential_members_imported = 17424

إذا ظهرت precheck_passed = 0، لا تعيدي التنفيذ ولا ترفعي ملفات CSV منفصلة. لم ينفذ الملف أي حذف أو إضافة في هذه الحالة. صوري النتيجة وأرسليها.

تنبيه: الملف يستبدل فقط بيانات branch_id = 1 (Fit90): الأعضاء والاشتراكات والأعضاء المحتملين، مع الإيصالات والبيانات المرتبطة اللازمة لمنع تعارض المفاتيح. لا يغير أنواع الاشتراكات أو إعدادات النظام أو أي فرع آخر.
